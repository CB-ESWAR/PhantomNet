## 🧠 About PhantomNet

PhantomNet is an explainable linguistic intelligence system designed to analyze text and identify signals associated with human and AI-generated writing.

Instead of relying on a single prediction signal, PhantomNet evaluates multiple independent linguistic characteristics and combines them into an overall analysis.

The system provides:

- 🤖 AI probability
- 👤 Human probability
- 🎯 Confidence score
- 🛡️ Reliability score
- 📊 Engine-level scores
- 🔎 Evidence signals
- 🧬 Model similarity
- 💡 Analysis recommendation

---

## ✨ Features

### 🔬 Multi-Signal Analysis

PhantomNet analyzes writing using multiple linguistic dimensions:

| Signal | Purpose |
|---|---|
| 📝 Stylometric | Examines writing style characteristics |
| 📊 Statistical | Evaluates statistical properties of text |
| 📖 Readability | Studies readability-related patterns |
| 🧬 Fingerprint | Extracts writing fingerprints |
| 🔗 Similarity | Compares text patterns against model signatures |

---

### 📄 Document Analysis

PhantomNet supports:

- `.txt`
- `.pdf`
- `.docx`

Users can either paste text directly or upload a document for analysis.
